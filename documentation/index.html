Template Manual

BrightPath Academy HTML Template

A modern, responsive HTML5, CSS3, JavaScript, Bootstrap 5 & Tailwind-ready template built for After-School Homework Help, STEM Discovery, and Academic Enrichment Centers.

Production Ready: Includes full Dark Mode, Right-To-Left (RTL) layout, WCAG 2.1 AA accessibility features, Parent Sign In portal, and an interactive Parent Dashboard for booking session slots, tracking homework completion notes, and viewing attendance logs.

3. Installation Guide

You do not need Node.js or complex build tools to run this template. It runs directly in any modern browser.

Option A: Quick Local Preview
  1. Unzip the template folder to your local drive.
  2. Double-click index.html (or pages/index.html) to open in Chrome, Firefox, Safari, or Edge.
Option B: VS Code Live Server
  1. Open the folder in VS Code.
  2. Install the Live Server extension.
  3. Right-click index.html and select "Open with Live Server".
Option C: Web Server Deployment (Apache, Nginx, Netlify, Vercel)

Upload all files directly to your public webroot (e.g. public_html/, /var/www/html, or drag & drop onto Netlify Drop).

4. Customization: Colors & Fonts

All visual branding colors are organized as CSS Variables in assets/css/style.css:

:root {
  --bp-primary: #2563eb;        /* Primary Brand Blue */
  --bp-secondary: #059669;      /* Growth Emerald Green */
  --bp-accent: #f59e0b;         /* Warm Gold/Amber */
  --bp-coral: #f43f5e;          /* Attention Coral */
  --bp-purple: #8b5cf6;         /* STEM Purple */

  /* Typography */
  --bp-font-heading: 'Outfit', sans-serif;
  --bp-font-body: 'Plus Jakarta Sans', sans-serif;
}

To change the primary color to violet, simply change --bp-primary: #7c3aed; and all buttons, badges, icons, and hero highlights update automatically.

5. Dark / Light Mode Toggle

The template features automatic system color scheme detection (via prefers-color-scheme) and persistent manual switching.

  • User preference is saved in localStorage under brightpath_theme.
  • Theme switches the data-theme="dark" and data-bs-theme="dark" attributes on the root <html> element.
  • Dark styles are neatly isolated in assets/css/dark-mode.css for effortless maintenance.

6. Right-to-Left (RTL) Layout Compatibility

For Arabic, Hebrew, and Persian audiences, click the "RTL" button in the navigation bar.

  • Toggles dir="rtl" on <html>.
  • Mirrors directional icons, chevron arrows, dashboard sidebars, and form inputs via assets/css/rtl.css.

7. Form & API Integrations

Contact Form (Formspree / Netlify Forms)

In pages/contact.html, replace the form action with your endpoint:

<form action="https://formspree.io/f/YOUR_FORM_ID" method="POST" class="needs-validation" novalidate>
Google Maps

In pages/contact.html, replace the iframe embed URL with your Google Maps embed URL.

Stripe / PayPal Checkout Placeholders

In pages/register.html, the credit card placeholder form is positioned for Stripe Elements or PayPal Buttons SDK.
